# M2 South West Arkansas project case

The [decision memo](decision_memo.md) is the case conclusion. The disclosed
DFS build forecast is held in [dfs_project_model.csv](dfs_project_model.csv)
with relative periods and 100% project scope. [dfs_reproduction.json](dfs_reproduction.json)
is an independent arithmetic check of the published model, with timing
uncertainty explicit. [alternatives.csv](alternatives.csv) registers both the
build option and the incomplete no-build/hold status quo.

The template `incremental_cash_flows.csv` and `sources_uses.csv` remain
header-only because a dated build-minus-status-quo option and executable
funding plan cannot be populated from the public report. Empty cells are not
zero. The M2 decision gate is `WITHHELD`.
