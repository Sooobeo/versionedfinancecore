# Intended and prohibited use

## Intended use

- 공개자료 기반 개인 연구·학습
- 재현 가능한 재무모델·의사결정 memo 포트폴리오
- 공개 당시 정보에 한정한 historical outcome analysis
- AI 보조를 받은 개인 분석·코드 작성. 독립 인간 검토 전의 제한적 결과 대조

## Prohibited use

- 실제 투자·대출·경영 승인 또는 외부 신용등급으로 표현
- 비공개 budget, customer, covenant, collateral 또는 guarantee를 아는 것처럼 표현
- 합성 fixture를 실제 회사의 관측값·성과로 표현
- 투자·법률·회계·세무 자문으로 표현
- 회사의 공개 가이던스를 내부 예산 또는 독립 분석가의 사전 예측으로 표현
- 실적과 가이던스의 차이를 공개되지 않은 driver의 인과 효과로 단정
