# Sector overlays

기본 상태는 `INACTIVE`다. 금융회사·Fintech, REIT 또는 PF처럼 일반기업의 재무·가치·신용 정의를 그대로 사용할 수 없는 case에서만 적용한다.

현재 outline에는 P5 상세 annex가 없으므로 금융서비스 overlay의 세부 구현은 보류한다.

Ford Credit is a finance company, so generic nonfinancial CFADS or EBITDA thresholds are not applied to this M3 pilot. A product/cohort financial-services overlay is **not activated**: the decision object is 2025 year-end issuer liquidity and debt structure, and the public slice does not establish product-level pricing, loss, capital and legal-jurisdiction inputs needed for an O1 conclusion. The credit memo remains a descriptive Mode C evidence-gap output.
