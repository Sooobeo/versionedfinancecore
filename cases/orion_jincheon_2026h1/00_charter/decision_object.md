# 오리온 진천센터 — R0 판단 객체 (타당성 확인 단계)

## 목적과 기준

- **용도:** 공개자료만 사용하는 개인 연구·학습·포트폴리오용 애널리스트 시뮬레이션. 실제 회사의 투자·예산·대출 승인이나 자문이 아니다.
- **판단시점:** 2026-08-18, 공개정보 cutoff 2026-08-18 23:59:59 KST. 비교기간은 cutoff 이후부터 2027-12-31까지다. 이후 공개된 자료나 정정 수치를 당시의 사실로 소급하지 않는다.
- **질문:** ㈜오리온의 진천센터 관련 **cutoff 이후 미집행 지출**을 계획대로 진행하는 경우와 단계적으로 집행하거나 이연하는 경우를 비교할 때, 모회사 범위의 증분 세후현금흐름과 접근 가능 유동성은 어떻게 달라지는가?
- **관점·경로:** `CORPORATE_VALUE`; M1의 기준 현금흐름을 먼저 고정한 뒤 M2의 자본배분 대안을 비교하고 M3에서 모회사 유동성 경계를 점검한다. 각 모듈은 아직 근거 gate를 통과하지 않았다.

## 비교할 두 세계

| 항목 | 정의 |
|---|---|
| 현상 유지 (`STATUS_QUO`) | cutoff에 확인 가능한 최신 공식 계획의 **남은 지출 일정**을 따른다고 가정하는 세계. 일정과 금액이 공시로 확인되지 않은 부분은 `UNKNOWN`으로 둔다. |
| 대안 (`OPTION_CASE`) | 동일한 cutoff 정보에서 이연이 법적·운영상 가능하다고 입증된 미집행 부분만 단계화 또는 연기하는 세계. 이연 가능 범위와 지연에 따른 비용·편익은 근거가 없으면 `UNKNOWN`이다. |

M2의 판단값은 기간별 `OPTION_CASE − STATUS_QUO` **증분 세후현금흐름**이다. cutoff 이전에 이미 지급했거나 취소할 수 없는 지출은 sunk cost로 제외한다. 취소 수수료·계약상 의무, 운영 개시 지연, 포기한 매출, 대체 시설의 기회비용, 기존 사업의 잠식 효과를 확인해야 한다. 차입 유입과 이자·원금 상환을 사업 자체의 FCFF와 중복 계산하지 않는다. 추정 세율·할인율·충격값을 근거 없이 채우지 않는다.

## 범위와 미확인 사항

- 경제적 분석 범위는 `orion_parent_standalone`, 법인 식별자는 `orion_co_ltd_kr`로 **잠정 설정**한다. 연결 재무제표 수치와 모회사 별도 재무제표 수치를 섞지 않는다. 센터 지출의 실제 계약·지급 주체, 자회사 또는 합작 범위, 내부거래는 공식 자료로 bridge를 확인해야 한다.
- 연결 기준 group cash는 곧바로 모회사 또는 해당 채무자의 접근 가능 현금이 아니다. 제한 예금, 해외·자회사 현금, 배당·이전 제약, 약정 신용한도와 비확약 자금의 구분을 확인하기 전에는 M3의 가용액을 `NOT_TESTABLE_FROM_PUBLIC_DATA`로 둔다.
- 프로젝트별 남은 투자액·지급일정·취소 가능성, 센터 단독 매출·비용·세금 효과, 운영 개시 시점, 계약상 페널티와 모회사 채무약정은 현재 미확인이다. 확인 불가하면 정량 NPV·유동성 여유·covenant·rating 결론을 `WITHHELD`로 유지한다.
- 이 문서는 질문과 검증 경계만 정한다. 투자 효과나 우월한 대안에 관한 수치·결론은 없다.
